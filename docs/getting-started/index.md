# Getting Started

Welcome to the Geotechnical Instrumentation Knowledge Base. This site is an **intranet-style reference** for engineers, researchers, and field technicians working with geotechnical instrumentation.

## Three ways to use this site

1. **By instrument type** — start at [Instrument Categories](categories.md) to find what you need by the parameter you're measuring (lateral movement, pore pressure, settlement, load).
2. **By instrument family** — start at [Instrument Categories](categories.md) to browse by what each instrument measures.
3. **By application** — start at [Applications](../applications/index.md) to see instrument arrays grouped by project type (slope, dam, tunnel, foundation).

## What's inside

- **instrument portfolio** — full product line catalog: piezometers, extensometers, inclinometers, data loggers, and the wireless platform. [Browse →](categories.md)
- **Reference manuals** — searchable references including Dunnicliff's *Geotechnical Instrumentation for Monitoring Field Performance* and the FHWA *Geotechnical Instrumentation Reference Manual*. [Browse →](../reference-manuals/index.md)
- **AI assistant** — the **GTI Doctor** chatbot answers technical questions using the manuals on this site as ground truth. [Try it →](../gti-doctor.md)
