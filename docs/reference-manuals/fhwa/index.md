# FHWA Geotechnical Instrumentation Reference Manual

!!! note "About this reference"
    This is an **original, open technical reference** on geotechnical
    instrumentation for highway and transportation works, written in plain
    engineering language. It is adapted from the subject scope and structure of
    the **FHWA *Geotechnical Instrumentation Reference Manual***
    (**FHWA-HI-98-034**, October 1998) — Module 11 of the National Highway
    Institute training course *Geotechnical and Foundation Engineering* (NHI
    Course No. 13241), authored by **John Dunnicliff** for the Federal Highway
    Administration. The source is a **U.S. Government work in the public domain**;
    this page is nevertheless an independent adaptation, **not** a verbatim
    reproduction. It is provided for education and field use, and every project is
    unique: the guidance here builds engineering judgment, it does not set minimum
    standards. The full manual is indexed in the [GTI Doctor](../../gti-doctor.md)
    AI assistant for deeper queries.

The **FHWA *Geotechnical Instrumentation Reference Manual*** is the training
manual that turns the theory of geotechnical instrumentation into a field-ready
system for **highway construction** — soil and rock slopes, embankments, deep
foundations, earth retaining structures, ground improvement, and grouting. It
shares its author and its systematic planning philosophy with Dunnicliff's
textbook, but it is written specifically for the transportation practitioner: it
recommends which instruments to use for each type of construction, and it supplies
the checklists and student exercises used in the NHI course.

This reference walks through the same arc: an overview of the hardware available
to measure groundwater pressure, deformation, total stress, and load/strain; a
**systematic approach to planning monitoring programs**; instrument selection for
each construction type; and the general field tasks — calibration, maintenance,
installation, data collection, processing, presentation, interpretation, and
reporting.

## How to use this reference

- **Start with Chapter 6.** The systematic planning process is the hub of the
  whole discipline — everything else supports it.
- **Then read the chapter for your construction type.** Chapters 7–11 each end
  with the *principal geotechnical questions* for that construction and the
  instruments that can answer them.
- **Use it with the rest of the knowledge base.** The instrument chapters
  cross-reference the [Dunnicliff](../dunnicliff/index.md),
  [Tailings Dam Safety](../tailings-dam-safety/index.md), and
  [Monitoring Dam Performance (MOP-135)](../monitoring-dam-performance/index.md)
  books for deeper theory and domain-specific application.
- **Ask the [GTI Doctor](../../gti-doctor.md).** The AI assistant can answer
  instrument-specific questions from the full FHWA and Dunnicliff corpus.

## The golden rule

Every instrument on a project should be selected and placed to assist with
answering a **specific geotechnical question**. If there is no question, there
should be no instrumentation.

> **Judgment is the instrument.** Instruments support, but never replace, the
> engineering judgment of a qualified geotechnical engineer.
